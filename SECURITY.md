# Security Policy

## Reporting a vulnerability

Please report security issues to sidsri1502@gmail.com.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/sidsri14/incidentlens-amd-sdk/issues

## Scope

This policy applies to the generated Siddharth Srivastava SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the IncidentLens AMD SDK public API, generated by
Siddharth Srivastava. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
